### About Me

I am a software developer with a passion for creative coding, procedural graphics, and interactive real-time tools. I specialize in turning complex ideas into high-performance web applications, fluid canvas rendering engines, and modular software architectures.

- **Creative Engineering:** Procedural typography engines, dynamic organic growth simulations, and 2D canvas physics.
- **Streaming & Realtime Tools:** Interactive OBS and TikTok Live Studio overlays, real-time WebSocket communication, and gamified rating platforms.
- **Performance First:** 60+ FPS browser graphics, zero-dependency lightweight servers, and clean component architecture.
